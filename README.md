# Online Store

A front-end online store where users can browse products, select options, add items to a cart, and save the cart locally.

## Live Demo

https://jfoster294.github.io/online-store/

## Features

- Browse product cards
- Search products
- Filter products by category
- Select product color
- Select product size or option
- Choose quantity
- Add products to cart
- Increase and decrease cart quantity
- Remove items from cart
- Clear cart
- View cart total
- Save cart with local storage
- Theme selector with saved theme preference
- Responsive design for mobile and desktop

## Theme Options

- Modern Store
- Black Luxury
- Neon Market
- Warm Boutique
- Clean Apple

## Built With

- HTML
- CSS
- JavaScript
- Local Storage

## Project Goal

This project was built as part of my front end developer portfolio to practice product UI, search, filtering, cart logic, local storage, theme switching, and responsive design.
